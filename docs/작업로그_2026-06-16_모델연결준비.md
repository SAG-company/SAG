## 3. 발견한 핵심 문제 (왜 이 작업이 필요했나)

| 항목 | 기존 `inference.py` | 최종 모델 `exp3_v4_final` |
|------|------|------|
| 프레임워크 | TensorFlow/Keras | **PyTorch** (불일치) |
| 로드 방식 | `tf.keras.load_model()` | `torch.load` + `load_state_dict` |
| 찾는 파일 | `mobilenetv3_skin.keras` | `exp3_v4_final.pt` (불일치) |
| 정규화 | 자체통계(0.56…) | **ImageNet통계(0.485…)** (불일치) |
| 리사이즈 | 단순 resize | **LetterboxResize**(종횡비 보존) (불일치) |

`.pt` 파일을 기존 `inference.py`에 넣어도 **조용히 더미 모드로 떨어진다**(에러도 안 남). 그래서 새 모듈이 필요했다.

> 학습 노트북(`models/exp3_v4_final.ipynb`)에서 확인한 정답값:
> - 백본: torchvision **EfficientNetB0**
> - 헤드: `Linear(1280→256)→ReLU→Dropout(0.5)→Linear(256→7)`
> - 입력: 224×224, 전처리: LetterboxResize → ToTensor → Normalize(ImageNet)
> - 클래스 순서: A1~A7 (알파벳 순, 인덱스 0~6)
> - 저장: `torch.save(model.state_dict())`, 출력은 **로짓**(추론 시 softmax 필요)
